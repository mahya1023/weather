# ☀️ Weather App - API Integration

## 📌 Introduction
This project is a **weather application** that fetches real-time weather data using an API. Users can enter a city name to get current weather details like temperature, humidity, wind speed, and weather conditions.

## 🚀 Features
✅ Fetches live weather data using an API  
✅ Displays temperature, humidity, wind speed, and weather conditions  
✅ Supports multiple cities worldwide  
✅ User-friendly interface with clean design  
✅ Works in all modern browsers
